# Search: Parametric Search


### 소개

> 어떤 값의 범위에서 "이 값이 가능한가"를 판단하면서
> 조건을 만족하는 최적의 값(min/max)를 찾는 이분탐색 기법

### 핵심 아이디어


<aside>
💡 값을 직접 찾는 게 이니라 -> 이 값이 조건을 만족하는가?를 본다
- 값이 커질수록 결과가 한 방향으로만 변해야 함(단조성)
- True/False가 딱 한 번 바뀌는 지점(경계)를 찾는다

</aside>

### 특징

- 배열을 탐색하는 게 아니라 값의 범위를 탐색
- 문제를 가능/불가능 판단 문제로 접근
- 이분 탐색이지만 값 찾기가 아니라 경계 찾기
    - binray search: 이 값이 어디에 있지?
    - parametric search: 이 값이 가능한가? -> 경계 찾기


### 필요 자료구조

- 반복문 + 조건 계산이면 충분

### 심화 / 유형

- 최댓값 찾기
    - 조건 만족 -> 더 크게 (left=mid+1)
      (최소 vice versa)
- 대표 문제
    - 나무 자르기 (2805)
    - 랜선 자르기 (1654)
    - 공유기 설치 (2110)
    
### 시간복잡도

<aside>
💡
- 이분탐색: O(log N)
- 매번 검사: O(N)
=> 총 O(N log N)

</aside>
