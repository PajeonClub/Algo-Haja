# Algo_HaJa

> 알고리즘을 정리합니다.

### 설명

* 1주 1알고리즘: 일주일에 각자 1가지의 알고리즘을 정리합니다.
* 상호 보완: PR에 올라온 정리를 다른 사람은 보충해줍니다.
* 언어별 구현: 각자 맡은 언어로 해당 알고리즘의 뼈대를 구현합니다.

----

### PR
* 하나의 PR은 하나의 문서입니다.
* 하나의 PR은 여러 개의 Commits로 이루어집니다.
* Commit은 세 종류입니다.

  1️⃣ [FEAT] 해당 알고리즘에 대한 설명

  2️⃣ [EDIT] 보충 설명, 피드백

  3️⃣ [FEAT] 언어 구현
----

### 일정

|  요일  |   Task    |
|:----:|:---------:| 
| 화요일  |  알고리즘 선정  |
| ~토요일 | 정리 PR 남기기 |
| 일요일 | 피드백 반영 후 Merge|
